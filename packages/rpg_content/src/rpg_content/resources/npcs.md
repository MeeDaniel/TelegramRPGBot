Правила npcs: role обязателен, непустая после trim строка. location необязателен, ссылка locations:id или null, default null.
lines — необязательный массив непустых реплик, default []. refs — необязательный массив ссылок на любые из шести секций, default []; повторяющиеся ссылки запрещены. Циклы ссылок допустимы. NPC — описание персонажа без runtime-состояния игрока и без исполнения диалога.
