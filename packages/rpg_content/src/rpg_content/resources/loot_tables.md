Правила loot_tables: entries обязателен, массив объектов добычи; [] означает отсутствие добычи.
Каждая строка требует item (ссылка items:id) и chance (конечное число от 0 до 1 включительно). min_quantity и max_quantity необязательны, целые >= 1, default 1, min_quantity <= max_quantity. Один item в таблице не повторяется. Шанс каждой строки независим; повышать его с редкостью будет потребитель.
