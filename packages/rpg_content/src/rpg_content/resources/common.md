Создай новые записи игрового мира. Ответ — один JSON-объект без Markdown и пояснений.
Обязателен schema_version: 1; canon необязателен, строка, default "". Используй канон задачи; при непустом canon дополнения он должен совпадать с каноном базы.
Каждая запись требует id и name. ID: [a-z][a-z0-9]*(?:_[a-z0-9]+)*; name непустой после trim. description необязателен, строка, default "".
Только перечисленные поля и типы; неизвестные и повторяющиеся ключи запрещены. Числа конечные; bool не заменяет число или целое. null разрешён только там, где указан явно. Списки текста состоят из непустых после trim строк. ID уникальны внутри секции; существующие записи не заменяются (add-only).
Ссылки имеют вид секция:id. Разрешены существующие записи из выбранных записей, их показанных прямых целей и индекса; также новые записи выбранной секции внутри ответа. Индекс разрешает ссылку без раскрытия подробностей. Не выдумывай существующие ID и не считай пример доступными данными мира.
Новые зависимости другой секции создавай отдельным запросом и добавляй в мир перед следующим context: сначала items, затем loot_tables, затем monsters, затем locations, npcs и story_seeds. Если доступных зависимостей недостаточно, уточни задачу у автора до генерации. Существующие записи дают контекст и доступные ссылки; автор может развивать мир в рамках задачи.
